# perp-lab

Reproducible discovery and validation of interpretable intraday trading
strategies on BTCUSDT and ETHUSDT USDT-M perpetual futures. This repository is
the research platform and the evidence base of a Master's Thesis in Data Science
(La Salle, URL).

## Result

**The study closed negative. No strategy was promoted.**

Sixteen families were evaluated as full multi-seed studies (2 assets x 10 seeds
x 15 expanding walk-forward folds) and six more as pilots, over **1,096,500
confirmatory candidate evaluations** under realistic costs (4 bps fee plus 1 bps
slippage per side, and realized funding). Counting the 750-evaluation S3 pilot
the total is 1,097,250.

Within the thirteen-family closure universe the smallest raw p-value is
**0.3455**, and both Holm and Benjamini-Hochberg return **zero rejections**. The
combinatorially symmetric cross-validation probability of backtest overfitting
is **0.4857**, and the mean selection optimism is **+4.04 Sharpe units**: picking
the in-sample winner carries essentially no out-of-sample information in this
space. Those study-level corrections cover the thirteen closure families only.
The nine CRT families and the S3 overlay were evaluated afterwards and carry
per-cell verdicts with no extended correction.

The reserved partition `[2026-01-01, 2026-07-01)` was opened once, on
2026-08-13, on a candidate the correction had already rejected. Its reading is
withheld pending a provenance audit, publication is locked in code, and the
partition is consumed: no clean confirmatory sample remains on this history. The
full chronology is in `docs/methodology/holdout_audit_status.md`.

What the negative does not say: markets are efficient, algorithmic trading does
not work, or these families are unprofitable in general. What it does say is
that nothing here survived an honest count of how many times we looked.

## Reproducing

```bash
uv sync --extra dev                              # locked Python 3.12 environment
uv run pytest -m "not network" -q                # test suite without the network case
uv run python -m perp_lab.cli download           # re-ingests from data.binance.vision
uv run python scripts/run_notebooks.py           # re-executes the eight notebooks
uv run python scripts/build_ch7_results.py       # chapter 7 evidence package
uv run python scripts/build_ch8_results.py       # chapter 8 evidence package
```

Market data is not committed; the manifests under `data/manifests/` are. A
re-ingestion must reproduce the recorded SHA-256 exactly, which is what makes
the datasets verifiable without redistributing them.

The web platform runs with `npm install && npm run dev` inside `apps/web`. The
in-browser laboratory is entirely client-side; the study pages read the API,
served with `uv run uvicorn perp_lab.api.main:app`.

Determinism is checked with `scripts/verify_determinism.py`, which executes a
notebook twice from a clean kernel and compares artefact hashes. The chapter
packages apply the same double-run check to their builders.

## Quality gates

Continuous integration (`.github/workflows/ci.yml`) runs on push and pull
request: `ruff check`, `ruff format --check`, a stale-claims sweep that fails
the build when a committed document asserts a result no artefact supports, and
`pytest -m "not network"`. Type checking with pyright, the web suites (112
vitest, 22 Playwright end-to-end), the production build and the determinism
checker are local gates and are not enforced by CI. All of them pass at commit
`a44399e`.

## Scope and limits

Two assets on one exchange, hourly bars, development window 2020-01-01 to
2025-12-31 with out-of-sample test slices from 2022-03-31 to 2025-12-09. The
data is OHLCV plus funding, with no order book, so there is no queue position,
no partial fills and no market-impact model. Execution is next-bar-open at fixed
fraction. The risk engine and the position-sizing configuration exist in code
but were inactive in every executed round. There is no live trading, no paper
trading and no external validation of any kind. The Monte Carlo work in the
thesis resamples the observed record and is a conditional diagnostic; it
validates no edge.
