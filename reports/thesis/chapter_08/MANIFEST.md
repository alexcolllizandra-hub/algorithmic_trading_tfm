# Chapter 8 — Simulation-Based Risk and Uncertainty Analysis
## Export manifest

Everything derives from archived development-period OOS artifacts (run-dir
paths in `ch8_input_returns.csv` provenance = `ch7_results_units.csv`
`run_dir` column). **No holdout access, no new searches, no config changes;
simulations are conditional diagnostics and alter no chapter-7 verdict.**
Regenerate with `uv run python scripts/build_ch8_results.py` (see
REPRODUCE.md; deterministic, master seed 20260829).
