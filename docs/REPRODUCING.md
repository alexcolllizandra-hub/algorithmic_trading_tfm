# Reproducing the results

Everything the thesis cites is regenerated by a command in this file. The
commands below are the ones that exist in the repository; nothing here is
aspirational.

## Environment

```bash
uv sync --extra dev                 # locked Python 3.12 environment (uv.lock)
npm --prefix apps/web install       # web platform, only if you want the site
```

Python is pinned to `>=3.12,<3.13` in `pyproject.toml` and the exact dependency
set lives in `uv.lock`. The web platform pins its own tree in
`apps/web/package-lock.json`.

## Data

Market data is not committed. What travels is the set of SHA-256 manifests
under `data/manifests/`, so a re-ingestion can be verified byte for byte:

```bash
uv run python -m perp_lab.cli download
```

This is the only step that needs network access, and it reads the public bulk
archive at `data.binance.vision`. One test is marked `network` and is excluded
in CI with `-m "not network"`. Everything else runs offline against the
artefacts already on disk.

provenance sidecars recording the dataset hashes, the resolved configuration
and the commit behind each one.

## Determinism

```bash
uv run python scripts/verify_determinism.py notebooks/05_study_closure_and_multiple_testing.ipynb \
    "reports/tables/closure/*.csv" "reports/figures/closure/*.png"
```

The checker executes a notebook twice from a clean kernel and compares the
SHA-256 of every artefact matching the given patterns, exiting with an error if
a single byte differs. Two sources of spurious difference are pinned rather
than tolerated: `SOURCE_DATE_EPOCH` is fixed so matplotlib stops stamping a
creation date into each PDF, and tables that group before sorting carry an
explicit tiebreak so tied rows cannot swap places between runs.

Byte-identical results recorded so far: 18 artefacts for notebook 05, 23 files
for the chapter 7 package, 35 for chapter 8, 14 for the chapters 9 to 11
material. The chapter builders apply the same double-run comparison to their
own outputs.

## Quality gates

Continuous integration runs on push and pull request and covers four things:
`ruff check`, `ruff format --check`, a sweep that fails the build when a
committed document asserts a result no artefact supports, and
`pytest -m "not network"`. Type checking with pyright, the web test suites, the
production build and the determinism checker run locally and are not enforced
by the pipeline.

```bash
uv run ruff check .
uv run pyright
uv run pytest
npm --prefix apps/web test
```
